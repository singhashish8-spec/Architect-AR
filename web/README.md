# Architect AR — web app

React + Vite + TypeScript. See [`../docs/`](../docs/README.md) for the
full picture — this file is deliberately minimal.

```
npm install
npm run dev         # local dev server
npm run lint         # ESLint
npm run typecheck    # tsc -b
npm run test         # Vitest
npm run build         # production build
```

Copy `.env.example` to `.env.local` and fill in real values before running
against a real Supabase project — see
[`../docs/engineering/environment.md`](../docs/engineering/environment.md).
