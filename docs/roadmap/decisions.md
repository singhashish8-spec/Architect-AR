| Why does rotating in the in-app 3D preview (not AR) feel like it pivots around the wrong point? | **A real, fixable bug — confirmed and fixed, 2026-08-09**: initially mistaken for the AR-handoff limitation above until the owner clarified it was about the ordinary preview, before ever tapping "View in AR." Root cause in this app's own code: `viewer/ModelViewer.tsx`'s `OrbitControls` was never given an explicit `target`, so it defaulted to world origin `(0, 0, 0)` — a Revit export is almost never centered exactly there, so every rotation pivoted around empty space until "jump to a level/room" happened to move it. Fixed by auto-framing the camera (and `controls.target`) around the whole model's bounding box the moment it loads or switches, reusing the same math the "jump to" feature already had. Verified against the real Duplex sample. See [`features/full-admin-dashboard.md`](../features/full-admin-dashboard.md). |
