# Release

> Part of [Architect AR docs](../README.md). What's needed to actually
> publish the native Android app to the Google Play Store — drafts and a
> checklist, written 2026-08-19 (Session 11) once the app itself was
> built and build-verified. See
> [`../history/sessions/2026-08-19-session-11.md`](../history/sessions/2026-08-19-session-11.md).

## Index

- [`publishing-checklist.md`](publishing-checklist.md) — what's left,
  step by step, and honestly, what could and couldn't be done from an
  automated session (account creation, payment, and real-device
  screenshots all need the owner directly).
- [`play-store-listing.md`](play-store-listing.md) — draft store listing
  copy (title, descriptions, category).
- [`privacy-policy.md`](privacy-policy.md) — draft privacy policy text,
  required by Play Console for an app requesting camera access; not yet
  hosted anywhere live.

The debug-signed APK this checklist assumes you've already tested is at
`releases/architect-ar-debug.apk` (repo root, not under `docs/`).
