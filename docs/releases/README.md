## Quick reference: what goes in a release file

Full detail in
[`../engineering/release-process.md`](../engineering/release-process.md).
Each file is `vX.Y.Z.md` and contains: the ask/reason it shipped, what's
new (linking to [`../features/`](../features/README.md) rather than
repeating it), how it works, known limitations, and links to the PR(s),
git tag, and [`../history/sessions/`](../history/README.md) file(s) that
produced it.
